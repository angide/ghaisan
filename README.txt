# Jadwal Ghaisan 🚀

Website jadwal sekolah sederhana dengan tema Astronot.

## Cara upload ke GitHub Pages

1. Upload semua isi folder ini ke repository GitHub.
2. Pastikan `index.html`, `style.css`, dan `script.js` berada di lokasi yang sama.
3. Buka **Settings → Pages**.
4. Pilih branch utama (biasanya `main`) dan folder `/ (root)`.
5. Simpan, lalu tunggu GitHub Pages aktif.

## Cara mengganti jadwal

Buka file `script.js`.

Semua jadwal ada di bagian:

`const scheduleData = { ... }`

Contoh:

`"Matematika", "Bahasa Indonesia", "PJOK"`

Catatan setiap hari juga bisa diganti di bagian `note`.

Tidak ada jam pelajaran pada website ini sesuai permintaan.
